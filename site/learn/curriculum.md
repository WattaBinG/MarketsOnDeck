## The order (and why)

The curriculum runs from "what is this thing" to "how do I not blow up,"
with income strategies in the middle — the same order a new trader should
learn them. Each lesson defines jargon on first use (house rule) and uses
real trades from the account where possible.

## Conventions for every lesson

1. Jargon defined on first use (inline or a "Key terms" table near the top).
2. At least one worked numerical example with the arithmetic shown.
3. A "Common mistakes" section.
4. Risk disclosure at top and bottom: educational only, options involve risk
   including possible loss of principal, not suitable for every investor,
   nothing here is a recommendation — do your own research.
5. Real account context where it fits (Trading/Agentic labels only — never
   account numbers): covered calls above cost basis, cash-secured puts at
   target prices, no pre-earnings option entries, the −33% kill switch.
6. No invented numbers: every formula and definition verified before publish.
